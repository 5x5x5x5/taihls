# Reproducibility & Running the Code

Every figure, simulation, and model in **TAIHLS** is generated by live, deterministic Python code (`random_state=0` or explicit `np.random.default_rng(...)` seeds). You can reproduce and remix every lab using the tier that best fits your setup.

## Tier 1 — Light interactive labs (in your browser, zero install)

All 20 chapters use only lightweight, Pyodide-compatible packages:

- `numpy` — numerical arrays and fast vector arithmetic
- `pandas` — tabular clinical data inspection
- `matplotlib` — publication-quality figures
- `scikit-learn` — standard datasets (`load_diabetes`, `load_breast_cancer`, `load_digits`) and classical models
- `scipy` — statistical utilities and signal helpers

Because every in-page chapter relies exclusively on built-in datasets or transparent self-contained biomedical generators, **no external downloads or API keys are required**, and pages execute both during static site builds and directly in your browser via **JupyterLite** (WebAssembly).

## Running the full book locally with `uv`

Exact package versions are pinned in `pyproject.toml` and `uv.lock` (with `requirements.txt` kept in sync for Binder).

```bash
git clone https://github.com/5x5x5x5/taihls.git
cd taihls
uv sync                                             # install exact pinned environment
uv run jupyter book start --execute                 # live preview at http://localhost:3000
uv run jupyter book build --html --execute --strict # build static HTML site into _build/html/
```

## Dataset provenance

- **Diabetes progression dataset** (`sklearn.datasets.load_diabetes`): 442 real clinical diabetes patients (Efron et al., 2004), ten baseline variables, and quantitative disease progression one year after baseline.
- **Wisconsin Breast Cancer dataset** (`sklearn.datasets.load_breast_cancer`): 569 real fine-needle aspirate (FNA) breast mass biopsies (Street et al., 1993), 30 cell-nucleus morphology features, benign vs. malignant outcomes.
- **Handwritten digits dataset** (`sklearn.datasets.load_digits`): 1,797 8×8 grayscale images used alongside synthetic microscopy/scan patches to introduce image arrays and 2D convolutions.
- **Biological sequences** (Part 4): Real N-terminal human hemoglobin beta (`HBB`), hemoglobin alpha (`HBA1`), human preproinsulin (`INS`), *Aequorea victoria* green fluorescent protein (`GFP`), and collagen repeat fragments for transparent offline sequence alignment and embedding analysis.
- **Pedagogical simulations** (epidemic SIR curves, Simpson's paradox confounding, hospital shortcut tags, proxy-label bias, differential privacy, and federated learning): Clearly marked synthetic generators crafted to isolate exact causal and statistical mechanisms with known ground truth.
