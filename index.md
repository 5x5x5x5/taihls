# Welcome

This is an interactive textbook about how artificial intelligence is used in
health and the life sciences. You don't just read it — you run it. Every example
is live code you can execute right in your browser.

<!-- PLACEHOLDER — replace the prose below with your own framing. The headings are the house style; keep them. -->

## What you'll learn

By the end of this book you will be able to:

- explain, in plain language, what the core ideas of modern AI actually *do*;
- read and tinker with small programs that apply those ideas to biological and
  medical data;
- reason about when an AI result can be trusted — and when it can't.

## Who it's for

Advanced high-school students and first-year undergraduates. We assume you're
curious and comfortable with **basic algebra** and a **little** programming. We do
**not** assume calculus or linear algebra, and we define every new term the first
time we use it.

## Prerequisites

- Comfort with algebra (variables, formulas, reading a graph).
- Willingness to run a line of code and see what happens.
- No prior AI, statistics, or biology coursework required.

## How to run the code

You have three options, easiest first — see [](back/reproducibility.md) for details:

1. **In your browser**, with nothing to install (powered by JupyterLite).
2. **Binder**, a free cloud environment.
3. **Locally** with [`uv`](https://docs.astral.sh/uv/).
